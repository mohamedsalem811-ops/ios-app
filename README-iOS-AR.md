# 💎 SALFORD Jewelry POS — iOS Edition (v5.7.0)
## منظومة مبيعات مجوهرات سالفورد — نسخة iOS (iPhone & iPad)

تحتوي هذه الحزمة على مشروع **Capacitor + Xcode iOS** الكامل لتطبيق **SALFORD Jewelry POS v5.7.0**، مع قاعدة بيانات محلية مدمجة (`IndexedDB + LocalStorage`) تعمل **100% بدون إنترنت (Offline)** على أجهزة iPhone و iPad.

---

## ✨ التحديثات والإصلاحات المضمنة في الإصدار v5.7.0

1. **قاعدة بيانات محلية مدمجة لنظام iOS (`IndexedDB`)**:
   - يعمل التطبيق بالكامل داخل جهاز الـ iPhone أو الـ iPad دون الحاجة لخادم Windows أو اتصال بالإنترنت.
2. **حفظ كامل لأسعار الصرف والدولار (`USD`)**:
   - تم إصلاح حفظ سعر الصرف وقت الشراء (`cost_rate`, `cost_usd`) وسعر الصرف وقت البيع (`sale_rate`, `total_sell_usd`, `total_cost_usd`, `profit_usd`) في جميع المبيعات، الأطقم، السجل، ولوحة التحكم، والإغلاق الربعي.
   - تعبئة تلقائية لسعر الصرف المحفوظ في الإعدادات داخل نوافذ البيع وإضافة المنتجات.
3. **إصلاح حساب خصم الأطقم (`Bundles / Sets`)**:
   - توزيع خصم الطقم تلقائياً على عناصر الفاتورة بحيث تتطابق الأرباح والإيرادات في التقارير والإغلاق الربعي بدقة تامة.
4. **دعم كاميرا ومكتبة صور iPhone/iPad للمنتجات**:
   - ضغط وحفظ صور المجوهرات محلياً داخل قاعدة البيانات ليعمل العرض بدون إنترنت.
5. **النسخ الاحتياطي والاستعادة عبر تطبيق الملفات (`iOS Files / iCloud`)**:
   - من صفحة **الإعدادات**، يمكنك تصدير نسخة احتياطية كاملة (`.json`) ومشاركتها إلى **iCloud Drive / Files / WhatsApp** أو استعادتها بضغطة واحدة.
6. **سجل مشتريات العميل وإيصال الفاتورة**:
   - نافذة لعرض تاريخ مشتريات كل عميل بالتفصيل، وزر لطباعة إيصال مبيعة أو حفظه كـ PDF عبر **AirPrint**.

## 📱 طرق تثبيت وتشغيل التطبيق على iPhone / iPad

### الطريقة 1: البناء عبر Xcode على جهاز Mac (Capacitor Native App)
1. افتح Terminal داخل مجلد المشروع وشغّل:
   ```bash
   npm install
   npx cap sync ios
   npx cap open ios
   ```
2. سيفتح مشروع Xcode (`ios/App/App.xcworkspace`).
3. من تبويب **Signing & Capabilities**، اختر حساب Apple ID الخاص بك (Team).
4. وصّل جهاز الـ iPhone أو الـ iPad واضغط **Run (▶)** لتثبيت التطبيق مباشرة على جهازك.

### الطريقة 2: استخراج ملف `.ipa` من Windows (بدون جهاز Mac) وتثبيته عبر Sideloadly أو AltStore
إذا كنت تستخدم جهاز Windows ولا تملك جهاز Mac:
1. ارفع هذا المجلد إلى مستودع خاص (Private Repository) على حسابك في **GitHub**.
2. يحتوي المشروع مسبقاً على ملف البناء الآلي `.github/workflows/build-ios-ipa.yml`.
3. ادخل إلى تبويب **Actions** في GitHub واضغط **Run workflow**؛ سيقوم خادم macOS السحابي ببناء التطبيق وإنتاج ملف **`SALFORD-Jewelry-POS-v5.7.0.ipa`**.
4. حمّل ملف `.ipa` على جهازك الـ Windows وثبّته على الـ iPhone باستخدام برنامج **Sideloadly** أو **AltStore**.

### الطريقة 3: التثبيت الفوري المباشر عبر Safari (بدون كمبيوتر)
1. افتح ملف `www/index.html` (أو ارفع مجلد `www/` على استضافة مجانية مثل GitHub Pages / Netlify / Vercel).
2. افتح الرابط في متصفح **Safari** على الـ iPhone أو الـ iPad.
3. اضغط زر **المشاركة (Share)** ثم اختر **إضافة إلى الشاشة الرئيسية (Add to Home Screen)**.
4. سيعمل التطبيق بملء الشاشة وبأيقونة SALFORD الذهبية وبدون إنترنت تماماً.
